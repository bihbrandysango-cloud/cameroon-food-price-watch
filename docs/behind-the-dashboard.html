It runs by itself. A GitHub Actions workflow runs every step on the 10th of each month: tests first, then fetch, build, forecast and export. If any data check fails, the run stops before anything is saved, so a bad month never reaches the dashboard.

Data engineeringbuilt

Getting reliable data in, keeping it tidy, and making sure it can be trusted every month without anyone touching it.

1. Fetching from an official API, safely

The first attempt downloaded the CSV file from HDX, but HDX's firewall blocks scripts with a bot check. Instead of working around it, the pipeline switched to HDX HAPI, the official API for programs, which asks each app to identify itself.

Large pages of 10,000 rows often arrived cut off, so the script asks for 2,000 rows at a time and retries broken pages. After the first full download it only re-fetches the last six months, because WFP sometimes corrects recent prices, and merges them in.

# src/ingest/fetch_wfp.py: new rows are added, corrected rows replace old ones
def merge(existing, fresh):
    merged = {tuple(r[k] for k in KEY): r for r in existing}
    merged.update({tuple(r[k] for k in KEY): r for r in fresh})
    return sorted(merged.values(), key=lambda r: tuple(r[k] for k in KEY[::-1]))

Every run is recorded in a manifest with the time, the mode, the row counts and a SHA-256 fingerprint of the file. If the data hasn't changed, nothing is saved. Latest run: refresh from May 2026, 2,756 rows downloaded, 0 changes.

2. Cleaning and storing with dbt and DuckDB

WFP records the same food in many sizes: maize per kg, and per 15, 18, 90 and 100 kg bag. In Maroua in September 2024, maize was 350 per kg and 35,000 per 100 kg bag, the same price. The staging model reads the pack size from the unit and converts everything to FCFA per kg (per litre for oil, per piece for eggs).

-- transform/models/staging/stg_wfp__prices.sql
coalesce(try_cast(regexp_extract(unit, '^([0-9.]+) ', 1) as double), 1) as pack_size,
...
price / case when unit_base = 'G' then pack_size / 1000 else pack_size end as price_per_unit

The warehouse has three layers: raw (as downloaded), staging (cleaned) and marts (ready for analysis and Power BI). Twenty-four data checks run on every build: no missing fields, no duplicate price for a market and month, no zero prices, and wholesale prices never more than 5 times retail (a sign a bag price wasn't divided).

Data sciencebuilt

Finding what's unusual, predicting what comes next, and being honest about how good the predictions are.

3. Seasonal anomaly detection (the alerts)

Prices rise and fall with the seasons, so a price is compared with the same month in the last five years, using the median so one extreme year can't distort "normal". It only looks at earlier years, never later ones, so the alert knows only what someone would have known at the time. A test proves this.

It flags both directions: 20% from normal is a watch, 40% is an alert. It caught the June 2024 lean-season spike in Maroua (+65%) and the 2026 crash (−62% in February).

4. Forecasting next month, tested honestly

A gradient-boosted tree model (scikit-learn) predicts next month's price for every market and food. It was tested month by month over the last year, each time trained only on data from before the month it predicted (5,136 predictions), and compared with two simple guesses.

MethodTypical errorWithin 10%Direction right on big moves
"Same as last month"3.2%69%–
"Copy last year's pattern"5.6%63%29%
Machine-learning model3.3%70%about 6 in 10

The honest result: the model is no more accurate than assuming the price stays the same, because prices are sticky (35% of the time they don't change at all). It does call the direction of big moves right about 6 times in 10, against 3 in 10 for last year's pattern. So the forecast is shown as a likely range, roughly 16% below to 17% above the estimate, and never as one exact number.

Data analysisin progress

What the data says. Page 1 of the dashboard is built; six more pages are planned.

Maize is in a price crash. In September 2026, 15 of 18 markets with enough history sold maize well below normal and none above. Mokolo is 65% below its usual September price. Good for buyers, hard for farmers.

The data has errors, and the pipeline found them. In September 2023 many markets jumped 3 to 10 times and dropped back the next month, a likely recording error. In April 2024 several Yaoundé and Douala markets list cassava at up to 6,400 FCFA "per kg", which are bag prices typed with the wrong unit.

Coverage is shrinking. WFP recorded about 16,000 prices in 2023 and about 4,000 in the first nine months of 2026. Limbé reported for 77 months, then stopped after December 2025.
